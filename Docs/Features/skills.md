# CobraSthenics — Skills

Skills track long-term calisthenics progressions such as Front Lever, Handstand, and L-Sit.

## Core Surfaces

- Skill overview
- Active skill focus
- Progress tiers
- Prerequisites
- Recommended drills
- Skill-specific training action

## Difficulty

Difficulty badges must follow the fixed mapping:

- BEGINNER: green
- INTERMEDIATE: orange
- ADVANCED: red
- ELITE: purple

## Data Needs

Skill features typically need domain entities and use cases for:

- Skill name
- Difficulty
- Current tier
- Progress percentage
- Prerequisites
- Recommended exercises
- Last trained date

## UI Rules

- Progress fills use scoped skill progress color, not interactive color unless the element is clickable.
- Tier dots fill left to right with the approved cascade animation.
- Skill actions use brand-blue buttons.
