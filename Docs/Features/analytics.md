# CobraSthenics — Analytics

Analytics help athletes understand consistency, progress, and training output without turning the app into a game.

## Core Metrics

- Workouts logged
- Day streak
- Skill progress
- Best holds
- PRs
- Weekly volume
- Completion rate

## Presentation Rules

- Numbers always lead labels.
- Numbers use DM Mono.
- XP, level, PR, and streak accents may use gold.
- Success and progress fills may use green.
- Interactive filters and links use brand blue.

## Charts

Charts should be calm and readable:

- Dark surfaces only.
- No decorative gradients unless defined in the design system.
- Avoid crowded labels.
- Use exact values for important stats.

## Empty States

Empty analytics states should point the user toward a real action, such as completing today's session or training an active skill.
