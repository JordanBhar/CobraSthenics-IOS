# CobraSthenics — Workouts

Workouts cover planned training sessions, active execution, rest, completion, and history.

## Core Surfaces

- Today's session
- Active program card
- Exercise sequence
- Timer and rest controls
- Completion summary
- Recent activity

## Content Rules

Use real movement names such as Tuck Front Lever, Weighted Dip +20kg, Ring Support Hold, Hollow Body Hold, and Bulgarian Split Squat.

## Data Needs

Workout features typically need domain entities and use cases for:

- Session title
- Exercise list
- Sets, reps, holds, duration, and rest
- Local completion state and queued sync state
- PR and streak effects
- Notes or form cues

## UI Rules

- Numeric values use DM Mono.
- Primary workout action uses brand blue.
- Completion stats lead with the number and caption underneath.
- Cards must use the standard card border and dark surface stack.
